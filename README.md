# Homebrew Tap

Custom Homebrew formulas by [Vivek Yadav](https://github.com/viveky259259).

## Install

```bash
brew tap viveky259259/tap
brew install mac-ai
```

## Formulas

| Formula | Description |
|---------|-------------|
| [mac-ai](https://github.com/viveky259259/mac-ai) | MCP orchestrator powered by Apple Foundation Models |

## Casks

```bash
brew install --cask viveky259259/tap/ambient
```

| Cask | Description |
|------|-------------|
| [ambient](https://yaml.cafe/) | Notch island, notifications and Dock glow for coding agents |
